# Power Query Automation for Recurring Reports

**Overview**  
An automated reporting pipeline built using Excel Power Query to reduce manual reporting, eliminate repetitive tasks, and standardize data refresh workflows.

**Business Problem**  
Daily and weekly reports were being refreshed manually, causing delays, version issues, and inconsistent data quality.

**Approach**  
- Built parameterized Power Query scripts that automatically pull data from SQL and Excel sources  
- Added transformations for cleaning, shaping, and validating data  
- Designed automated refresh logic to reduce manual effort  
- Created template files for teams to reuse across reporting functions  

**Tech Stack**  
Power Query  
Excel  
SQL  
ETL concepts  

**Impact**  
- Reduced manual reporting effort by around 40 percent  
- Improved data consistency and eliminated version confusion  
- Faster turnaround for daily and weekly reporting cycles
