# Zapier Reporting Workflow Automation

**Overview**  
A low code automated workflow built using Zapier to collect event data, transform it, and push structured summaries into reporting databases or sheets.

**Business Problem**  
Teams needed daily and weekly insights from multiple tools, but exporting and merging this data manually was time consuming and error prone.

**Approach**  
- Created multi step Zaps to pull data from forms, CRMs, and analytics tools  
- Cleaned and transformed raw data using formatter and lookup steps  
- Pushed cleaned output to Google Sheets or a database for reporting  
- Added scheduled daily and weekly summary tasks  
- Integrated email alerts for leadership summaries  

**Tech Stack**  
Zapier  
Google Sheets  
Webhooks  
APIs  
Automation logic  

**Impact**  
- Saved hours of manual data collection every week  
- Ensured teams received consistent automated reports  
- Improved visibility into daily operations and campaign performance
