# Financial & Operational Reporting Dashboard

**Overview**  
A Power BI reporting suite to track revenue, margins, transaction trends, and detect anomalies for finance and operations teams.

**Business problem**  
Finance needed fast, accurate visibility into revenue trends and an early warning system for anomalies affecting monthly revenue and reconciliation.

**Data used**  
- Transactional revenue tables (SQL)  
- Product and geography metadata via API  
- Cost and operations data  
- Aggregated daily KPIs

**Approach**  
- Aggregated transactional data to create hourly/daily summaries  
- Built DAX measures for revenue, margin, MoM and YoY comparisons  
- Implemented anomaly detection rules and drilldowns by product and region  
- Designed exportable reports for monthly close and finance reviews

**Tech stack**  
Power BI  
SQL  
Power Query  
DAX
